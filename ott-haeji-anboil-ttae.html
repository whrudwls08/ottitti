해지 버튼이
안 보일 때

앱을 다 뒤져도 해지 메뉴가 없는 건 오류가 아니라, 대부분 결제처가 다르다는 신호예요.

원인을 일곱 가지로 나눠서 확인 순서를 정리했습니다.

먼저 알아 두면 좋은 원칙

OTT 구독의 해지 권한은 돈을 받은 쪽에 있어요. 서비스가 직접 결제를 받았으면 서비스에서, Apple이 받았으면 Apple에서, 통신사가 받았으면 통신사에서 취소합니다. 그래서 인앱 결제로 가입한 구독은 OTT 앱 안에 해지 버튼이 아예 없는 게 정상이에요.

아래 원인들을 위에서부터 확인해 보시면 대부분 두세 번째 항목에서 답이 나옵니다.

원인 일곱 가지

해당할 만한 항목부터 확인해 보세요.

1. 스토어 인앱 결제

가장 흔한 경우예요. 설정 → Apple 계정 → 구독, Play 스토어 → 결제 및 구독 → 구독에서 취소합니다. 앱스토어 안내

2. 통신사 부가서비스

요금제 혜택·결합으로 받는 OTT는 통신사 앱의 부가서비스·구독 메뉴에서 해지해요. 통신사 안내

3. 번들 상품

디즈니+·티빙·웨이브 번들은 한 상품으로 청구돼서, 개별 서비스 앱에서는 나눠 해지되지 않아요. 번들 안내

4. 다른 계정으로 가입

소셜 로그인 방식이 달라서 빈 계정에 들어간 경우예요. 카카오·네이버·구글·애플 로그인을 바꿔 시도해 보세요.

5. 가족 공유·대표 회선

결제 담당자 계정에만 구독이 표시되는 구조예요. 가족 공유 가이드에서 주체를 확인해 보세요.

6. 앱에서는 숨겨진 메뉴

앱 정책상 결제·해지 화면을 노출하지 않는 경우가 있어요. PC 웹 브라우저로 로그인하면 보이는 경우가 많습니다.

7. 이미 해지된 상태

해지 예약이 끝난 구독은 취소 버튼이 사라져요. 대신 “○월 ○일까지 이용” 문구나 재가입 버튼이 보입니다.

보너스. 약정·연간 상품

연간 이용권·약정 상품은 즉시 해지 대신 문의·신청 절차로 안내되는 경우가 있어요. 고객센터 안내를 따라 주세요.

확인 순서

위에서부터 차례대로 짚어 가면 빠져나가는 경우가 거의 없어요.

  1. 명세 표기 확인 — 결제처를 좁히는 가장 빠른 방법이에요 (표기 사전)
  2. 스토어 구독 목록 열기 — Apple·Google 양쪽 다 확인합니다. 계정이 여러 개면 계정별로 봐 주세요
  3. 통신사 청구 상세 열기 — 부가서비스·구독·제휴 항목을 봅니다
  4. PC 웹으로 로그인 — 앱에 없던 멤버십·이용권 메뉴가 웹에 있을 수 있어요
  5. 로그인 방식 바꿔 보기 — 가입 확인 메일에서 어떤 방식으로 가입했는지 찾아봅니다
  6. 고객센터 문의 — 위에서 다 안 나오면 아래 정보를 모아 문의합니다

고객센터에 전달하면 좋은 정보

처음부터 함께 알려 주면 확인이 훨씬 빨라져요.

  • 결제일과 금액 — 최근 2~3건이면 충분해요
  • 카드 명세 표기 — 가맹점 이름 그대로 적어 주세요
  • 가입에 썼을 것 같은 계정 — 이메일 주소, 소셜 로그인 방식, 휴대폰 번호
  • 이미 시도한 절차 — 스토어 구독 확인, 통신사 확인, 웹 로그인 등
  • 요청 사항 — “구독 해지”인지 “결제처 확인”인지 명확히 적어 주세요

통신사 상담에서는 “OTT 부가서비스만 해지”처럼 범위를 분명히 말씀해 주시는 게 좋아요. IPTV·인터넷 결합과 묶여 있으면 의도치 않게 다른 상품까지 영향을 줄 수 있습니다.

해지했다고 나오는데 결제가 될 때

해지 처리와 청구는 시점이 어긋날 수 있어요.

해지 예약 구간 — “다음 결제부터 중단”이면 이번 주기 요금은 정상 청구돼요. 해지 확인 문구를 다시 읽어 주세요.

다른 결제처에 남은 구독 — 웹에서 해지했는데 스토어 구독이 남은 경우가 많아요. 중복 결제 점검을 확인해 보세요.

통신사 정산 주기 — 통신 요금은 청구 주기가 달라서 다음 청구서에 한 번 더 반영될 수 있어요.

카드 정지로는 안 끝나요 — 결제가 실패해도 구독 자체는 유지되는 경우가 많습니다. 반드시 구독 메뉴에서 해지해 주세요.

환불이 필요하면 — 환불 문의 가이드에서 결제처별 창구를 확인해 보세요.

자주 묻는 질문

해지 메뉴를 못 찾을 때 자주 나오는 질문이에요.

앱에 해지 메뉴가 왜 없나요?

스토어·통신사·번들에서 결제된 구독은 그 결제처에서만 취소할 수 있어요. 이 경우 OTT 앱에 해지 버튼이 없는 게 정상 동작이에요.

웹 브라우저에서 시도하면 달라지나요?

직접결제 구독은 앱보다 웹에서 해지 메뉴를 찾기 쉬운 경우가 있어요. PC 브라우저로 로그인해 계정·멤버십 화면을 확인해 보세요.

로그인했는데 구독 정보가 아예 없어요

다른 계정으로 가입했을 가능성이 커요. 카카오·네이버·구글·애플 중 어떤 방식으로 가입했는지 가입 확인 메일에서 찾아보세요.

고객센터에 문의할 때 무엇을 알려 주면 되나요?

결제일·금액, 카드 명세 표기, 가입에 썼을 것 같은 계정과 로그인 방식, 이미 시도한 확인 절차를 함께 전달하면 확인이 빨라져요.

계정을 삭제하면 해지되나요?

권하지 않아요. 계정 삭제와 구독 해지는 별개로 처리돼서, 결제처에 구독이 남아 청구가 계속될 수 있어요. 먼저 구독을 해지한 뒤 계정 정리를 진행해 주세요.
